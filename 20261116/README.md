- 수강생 배포: `mentee/` 전체. 시작은 `mentee/START_HERE.html` 또는 `mentee/README.md`.
- 강사 보관: `mentor/` 전체. 시작은 `mentor/INSTRUCTOR_GUIDE.md`.
