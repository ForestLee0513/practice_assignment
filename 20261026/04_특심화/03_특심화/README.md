# 실습 03 — FP·FN 사례와 제한된 C 실험 / 심화

PPT 34 · 85쪽 · 실습 시간 20분. 기본필수를 먼저 완료한 뒤 다음 단계를 선택합니다.

## 목표

공통 로지스틱 모델의 FP·FN을 각1건 살펴보고 C=0.1/1/10만 추가 비교합니다. 동점은 작은 C를 선택합니다.


## 진행 순서

먼저 예상 값을 학습기록에 적습니다. 해당 코드의 TODO 함수에 입력·반환값 계약을 확인하고 구현합니다.
한 번에 많은 설정을 바꾸지 말고 현재 단계의 고정 조건을 유지합니다.
실행 후 `expected_output.txt`와 `expected_outputs/`의 수치·shape를 대조하고 자동 검사를 실행합니다.
마지막에 학습기록의 해석 질문에 답합니다. 점수만 기록하고 끝내지 않습니다.

역할 폴더에서 실행합니다.

```bash
python run.py 03 advanced
python tools/check.py --exercise 03 --level advanced
```

직접 실행 파일: `ex03_logistic/03_심화/main.py`. 실행 결과: `outputs/result.json`와 결과에 포함된 표의 CSV.
01~06을 실행해도 이전 단원 파일을 수정하거나 원본 데이터를 덮어쓰지 않습니다.

## 구현할 함수

### `main.py :: error_examples()`

FP와 FN을 ID 오름차순으로 각각 1건 선택해 입력·실제·예측·실패확률을 포함한 표 반환.
오류가 없는 유형은 행을 만들지 않는다. index를 섞거나 valid 행을 삭제하지 않는다.

### `main.py :: compare_C()`

C만 바꾼 모든 후보의 valid F1·FP·FN 기록. C 오름차순을 동점 규칙으로 사용한다.
