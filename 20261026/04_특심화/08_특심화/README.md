# 실습 08 — 최종 검증·시연·지표 선택 근거 / 심화

PPT 74~78쪽 · 실습 시간 35분. 기본필수를 먼저 완료한 뒤 다음 단계를 선택합니다.

## 목표

정상·경계·실패 테스트를 시연하고 다음 모델에도 유지할 계약과 평가 정책을 문서화합니다.
작업 대상은 **`ex07_compare/03_심화/day6_compare`**입니다. 08에서도 이 폴더를 그대로 사용합니다.
먼저 `python run.py 07 advanced`로 결과를 생성합니다. 새 프로그램을 만들거나 다시 분할하지 않습니다.


## 진행 순서

실습 07의 미완성 함수를 먼저 완성합니다. 실습 08에서는 같은 프로젝트의 결과를 검증하고 보고서를 작성합니다.
한 번에 많은 설정을 바꾸지 말고 현재 단계의 고정 조건을 유지합니다.
실행 후 이 폴더의 `expected_output.txt`와 `ex07_compare/03_심화/expected_outputs/`의 수치·shape를 대조합니다. 예상 결과는 대조용이며 프로그램의 입력이 아닙니다.
마지막에 학습기록의 해석 질문에 답합니다. 점수만 기록하고 끝내지 않습니다.

역할 폴더에서 실행합니다.

```bash
python run.py 08 advanced
python tools/check.py --exercise 08 --level advanced
```

직접 실행 파일: `ex08_validate/03_심화/check_submission.py`. 실행 결과: `ex07_compare/03_심화/day6_compare/outputs/`의 비교표·예측·탐색·검사 기록.
01~06을 실행해도 이전 단원 파일을 수정하거나 원본 데이터를 덮어쓰지 않습니다.

## 구현할 함수

08에서는 07의 구현을 검증하고 보고서를 완성합니다. `check_submission.py`는 제공된 검사 실행기이므로 미완성 함수를 추가하지 않습니다.

## 완료 기준과 제출

README의 목표 수치·반환 형태를 확인하고 `학습기록.md`를 작성합니다.
코드·직접 생성한 결과·검사 로그가 서로 같은 실행에서 나온 것인지 확인합니다.
07~08은 `reports/model_choice.md`와 Git 변경 이력도 제출합니다. test 점수는 제출하지 않습니다.
