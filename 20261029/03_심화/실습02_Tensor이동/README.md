## 내 기록

> pytorch의 일부 배열/행렬 제어하는 내용이 numpy와 유사해서 알면 더 좋을 듯 하다.

- 확인한 입력 / 출력:
  - `torch.arange(12, dtype=torch.float32)`로 0부터 11까지 채운 `(12,)` Tensor를 생성했다.
  - `reshape(3, 4)`로 원소를 유지하면서 3행 4열로 바꾸고, `[1, 2, 3, 4]`를 브로드캐스팅으로 각 행에 더했다.
  - 보정 결과는 `[[1., 3., 5., 7.], [5., 7., 9., 11.], [9., 11., 13., 15.]]`이다.
  - 앞의 두 열을 선택한 입력 `X`는 `[[1., 3.], [5., 7.], [9., 11.]]`이며 shape은 `(3, 2)`, dtype은 `torch.float32`이다.
  - 정답 `y`는 `[0, 0, 1]`이며 shape은 `(3,)`, dtype은 `torch.long`이다.
  - `nn.Linear(2, 2)`의 순전파 출력 `logits`는 shape이 `(3, 2)`, dtype이 `torch.float32`이다. 코드의 장치 일치 확인식은 `True`가 되어야 한다.
- 결과의 의미:
  - `X`, `y`, `model`에 각각 `.to(device)`를 적용해 CUDA 사용이 가능하면 `cuda:0`, 아니면 CPU에 배치한다. 모델을 이동하면 가중치와 편향도 함께 이동한다.
  - `.to(device)`는 여기서 장치만 바꾸므로 각 Tensor의 dtype은 유지된다. 같은 device를 사용한다고 dtype까지 같아야 하는 것은 아니다.
  - 입력 `X`와 모델의 가중치·편향은 `float32`로 맞춰 선형 연산을 수행한다. `logits = model(X)`는 `X @ weight.T + bias`를 계산하며, 출력도 `float32`이다.
  - 입력의 `(3, 2)`는 샘플 3개와 샘플당 특징 2개를 뜻한다. 출력의 `(3, 2)`는 각 샘플에 대한 클래스 2개의 점수(logit)를 뜻한다. 입력과 출력의 열 수가 같은 이유는 이번 모델이 `Linear(2, 2)`이기 때문이다.
  - `logits`는 확률이나 최종 예측 번호가 아닌 점수이다. 예측 클래스 번호는 `logits.argmax(dim=1)`로 구할 수 있다.
  - 정답 `y`는 순전파에 직접 사용되지 않는다. 이후 `nn.CrossEntropyLoss()`에 클래스 번호 형태의 정답을 전달할 때 `torch.long`을 사용한다. 이때 출력과 정답도 같은 device에 있어야 한다.
- 잘못 이해했던 내용 또는 질문:
  - `arange(12)`는 값이 없는 Tensor가 아니라 0 이상 12 미만의 값을 순서대로 채운다.
  - `reshape(3, 4)`는 배열 12개를 만드는 것이 아니라 원소 12개를 가진 하나의 Tensor 모양을 바꾼다.
  - `[1, 2, 3, 4]`를 더할 때 첫 번째 열에는 1, 두 번째 열에는 2, 세 번째 열에는 3, 네 번째 열에는 4를 더한다. `sum()`으로 원소를 합산하는 연산과 다르다.
  - 보정에 사용하는 정수 Tensor의 기본 dtype은 `int64`지만, `float32` 행렬과 더한 결과는 타입 승격에 따라 `float32`이다.
