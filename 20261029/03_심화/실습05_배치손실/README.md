## 내 기록

- 확인한 입력 / 출력:
  - 입력은 미리 만든 logits 10개의 `(10, 2)` Tensor이며, 정답은 모두 클래스 0인 `(10,)` 크기의 `torch.long` Tensor이다.
  - `DataLoader`에서 배치 크기를 4로 지정했으므로 실제 배치는 4개, 4개, 2개로 나뉜다. 이번 코드의 `xb`는 배치 logits, `yb`는 대응하는 정답이다.
  - `CrossEntropyLoss()`는 기본적으로 배치의 평균 손실을 반환한다. 각 평균에 `len(xb)`를 곱해 손실 합계를 누적한 뒤 전체 샘플 수 10으로 나눴다.
  - 실행 결과 배치 평균의 단순 평균은 `1.048587`, 샘플 수 가중 평균과 전체 데이터를 한 번에 계산한 평균 손실은 모두 `0.648587`이었다.
- 결과의 의미:
  - 처음 8개는 정답 클래스 0에 높은 점수를 준 `[3., 0.]`이고, 마지막 2개는 오답 클래스 1에 높은 점수를 준 `[0., 3.]`이다. 따라서 마지막 배치의 평균 손실이 더 크다.
  - 배치 평균을 단순히 더해 3으로 나누면 샘플 2개인 마지막 배치에도 샘플 4개인 배치와 동일한 비중을 준다. 이 때문에 전체 샘플 기준 평균보다 큰 값이 나왔다.
  - 실제 배치 크기를 곱한 가중 평균은 각 샘플에 같은 비중을 주므로 전체 데이터를 한 번에 계산한 평균 손실과 일치한다.
- 잘못 이해했던 내용 또는 질문:
  - `batch_size=4`는 설정한 크기이며 마지막 배치의 실제 크기를 보장하지 않는다. 실제 크기는 `len(xb)` 또는 `xb.shape[0]`으로 확인한다.
  - 여기서 `xb`는 모델에 넣을 원본 특징이 아니라 이미 계산된 예측 점수이다. `yb`는 모델에 직접 넣는 입력이 아니라 손실 계산에 사용하는 정답이다.
  - 손실값은 오답 비율을 뜻하는 오류율과 다르다. 정답 클래스에 부여한 점수에 따라서도 달라진다.

### 전체 손실과 평균 계산 대조

아래 값은 표시할 때 소수점 여섯 자리로 반올림했다. 계산에는 반올림 전 값을 사용한다.

| 배치 | 실제 샘플 수 | 배치 평균 손실 | 배치 손실 합계(평균 × 샘플 수) |
| --- | --- | --- | --- |
| 1 | 4 | 0.048587 | 0.194349 |
| 2 | 4 | 0.048587 | 0.194349 |
| 3 | 2 | 3.048587 | 6.097175 |
| 전체 | 10 | — | 6.485873 |

| 비교 항목 | 계산 방법 | 결과 |
| --- | --- | --- |
| 전체 손실 합계 | 각 배치 평균 × 실제 배치 크기의 합 | 6.485873 |
| 전체를 한 번에 계산한 평균 손실 | `loss_fn(logits, y)` | 0.648587 |
| 샘플 수 가중 평균 | `(평균1×4 + 평균2×4 + 평균3×2) / 10` | 0.648587 |
| 배치 평균의 단순 평균 | `(평균1 + 평균2 + 평균3) / 3` | 1.048587 |

전체 손실 **합계**와 전체 평균 손실은 구분해야 한다. 합계는 약 `6.485873`이고, 이를 샘플 수 10으로 나눈 값이 약 `0.648587`이다. 이번 코드에서 `전체를 한 번에 계산`으로 출력하는 값은 기본 설정이 `reduction="mean"`이므로 합계가 아닌 평균이다.

```python
total_loss += loss.item() * len(xb)  # 배치 손실 합계를 누적
count += len(yb)                    # 전체 샘플 수를 누적
# 모든 배치를 처리한 뒤
average_loss = total_loss / count
```

실행 결과 가중 평균과 전체 평균이 소수점 여섯 자리까지 일치했다. 배치 평균의 단순 평균은 마지막 고손실 배치의 비중을 실제 샘플 비중인 `2/10` 대신 `1/3`로 높이므로, 전체 평균보다 약 `0.4` 크게 계산됐다.

마지막 배치가2건이므로 (배치 평균의 합)/3은 전체 평균이 아닙니다. 이 예제에는 class 가중치와 ignore_index를 사용하지 않습니다. 가중치 손실에서는 분모 규칙을 다시 확인해야 합니다.
