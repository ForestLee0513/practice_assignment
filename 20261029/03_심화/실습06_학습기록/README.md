## online loss와 고정 모델 평가 loss 기록

`outputs/training_history.csv`와 콘솔에서 다음 값을 구분해 기록합니다.

- `train_loss_online`: 해당 epoch에서 각 배치를 갱신하기 직전 계산한 loss를 배치 표본 수로 가중 평균한 값입니다. 배치마다 서로 다른 시점의 모델로 측정하며, 마지막 배치 크기가 달라도 표본별 가중치가 같도록 계산합니다.
- `train_loss_eval`: 해당 epoch의 모든 갱신이 끝난 모델을 `eval()`·`no_grad()`로 평가한 전체 train loss입니다.
- `valid_loss`: 같은 고정 모델로 평가한 전체 valid loss입니다.
- `valid_accuracy`: 같은 시점의 valid 정확도입니다.

기존처럼 10 epoch마다 기록합니다. online loss는 직전 10 epoch의 평균이 아니라 기록된 해당 epoch 한 번의 값입니다. epoch 0은 학습 전이므로 online loss는 콘솔에서 `N/A`, CSV에서 빈칸으로 남깁니다. 위 예상 출력의 train loss는 `train_loss_eval`에 해당하며, 현재 콘솔은 각 값에 열 이름을 붙여 출력합니다. CSV에는 반올림 전 값을 저장합니다.

### 실제 실행 결과

아래 값은 `main.py`를 실행해 생성한 [training_history.csv](outputs/training_history.csv)를 기준으로 작성했습니다. loss는 소수점 여섯 자리, 정확도는 네 자리로 표시했습니다.

| epoch | online train loss | 고정 모델 train loss | valid loss | valid 정확도 |
| --- | ---: | ---: | ---: | ---: |
| 0 | N/A | 0.565832 | 0.510637 | 0.7000 |
| 10 | 0.342276 | 0.331469 | 0.281476 | 0.9750 |
| 20 | 0.234005 | 0.228078 | 0.182579 | 0.9750 |
| 30 | 0.180513 | 0.176405 | 0.134341 | 1.0000 |
| 40 | 0.147421 | 0.145632 | 0.105641 | 1.0000 |
| 50 | 0.126812 | 0.125040 | 0.086818 | 1.0000 |
| 60 | 0.111919 | 0.110228 | 0.074174 | 1.0000 |
| 70 | 0.099610 | 0.098804 | 0.064484 | 1.0000 |
| 80 | 0.090861 | 0.089844 | 0.057217 | 1.0000 |

이번 실행에서는 epoch 80의 online loss가 0.090861, 고정 모델 train loss가 0.089844였습니다. online loss는 학습 도중 계속 갱신되는 모델로 계산하고, 고정 모델 train loss는 해당 epoch의 갱신이 모두 끝난 모델로 계산하므로 값이 다릅니다. 이번에는 평가 loss가 더 낮았지만 항상 이 순서가 보장되는 것은 아닙니다.

valid loss는 학습 전 0.510637에서 epoch 80의 0.057217로 감소했고, valid 정확도는 0.7000에서 1.0000으로 높아졌습니다. 이는 현재 valid 데이터의 결과이며, 새로운 데이터에서도 정확도가 100%라는 의미는 아닙니다. test 40건은 모델에 전달하지 않았습니다.
