# 심화 · 기존 응용 수준, 체계적인 폴더 구조

기본필수·응용과 같은 주제를 확장합니다. **자료의 수준을 원래 심화로 되돌리지 않습니다.** 실습별 README, 제공 전처리 모듈, data/·expected/·outputs/, 종합 reports/의 역할을 익힙니다.

| 실습 | 먼저 읽을 문서 | 핵심 확장 |
|---|---|---|
| 01 | [회귀 트리](실습01_회귀트리/README.md) | 잎별 평균·외삽 |
| 02 | [잎 크기](실습02_잎크기/README.md) | min_samples_leaf=1·3·5 |
| 03 | [회귀 숲](실습03_회귀숲/README.md) | 트리 수20·100, MAE·RMSE |
| 04 | [순열 중요도](실습04_순열중요도/README.md) | 원본4열을 섞었을 때 F1 변화 |
| 05 | [XGBoost 회귀](실습05_XGBoost회귀/README.md) | 회귀 목적·실행시간 정답 |
| 06 | [회귀 CV](실습06_회귀교차검증/README.md) | 동일 KFold·음수 RMSE scorer |
| 07~08 | [종합 프로젝트](day7_ensemble/README.md) | 모듈 재사용·분류/회귀 비교·저장·복원·보고서 |

각 실습은 해당 폴더를 열고 `python main.py`로 실행합니다. 폴더를 혼동하지 않도록 실습이 바뀔 때 VS Code 상단과 터미널 위치를 확인합니다. 데이터와 경로는 .py 위치를 기준으로 읽기 때문에 다른 터미널 위치에서도 절대 경로로 실행할 수 있습니다.

**data/** 원본 입력 / **expected/** 미리 계산한 비교용 결과 / **outputs/** 내가 실행해서 만든 결과 / **reports/** 나의 설명 문서.

01~06은 독립 실행되며 다른 실습의 outputs를 읽지 않습니다. 07~08은 같은 day7_ensemble 폴더를 이어갑니다. 이전 실습을 못 끝냈어도 제공된 전처리·평가 모듈을 활용할 수 있습니다. GridSearchCV·조기 종료·복잡한 입력 검증·자동 테스트 작성은 이번 심화의 필수 범위가 아닙니다.
