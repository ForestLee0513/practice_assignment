## 제공 코드에서 알아둘 것

`HERE`는 지금 실행하는 .py 파일이 있는 폴더입니다. `pd.read_csv`는 CSV를 읽습니다. `train`은 배우는12건, `valid`는 확인하는4건이며, `test`4건은 보관합니다. `[["input_chars"]]`는 입력을 2차원 표로 유지하는 선택입니다. 난수42와 분할 비율을 바꾸지 않습니다.

`model.fit(X_train, y_train)`은 입력과 정답으로 배우는 단계, `model.predict(X_valid)`는 새 입력의 정답을 예측하는 단계입니다. 출력에 맞춰 예측값을 직접 적지 않습니다.

**이번 합성 자료는 관계가 단순하지 않습니다. F1=0도 고장이라는 뜻이 아닙니다.** 실제 실패1건을 못 찾았을 수 있으므로 정답과 예측을 함께 읽습니다. 먼저 코드가 실행되도록 완성하고, 아래 예상값과 다를 때 설정·입력·버전을 확인합니다.
